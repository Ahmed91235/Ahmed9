# Ahmed App

A simple React app that displays "Ahmed" with a beautiful gradient background and pulse animation.

## Features

- 🎨 Beautiful gradient background (purple to blue)
- ✨ Animated "Ahmed" text with a subtle pulse effect
- 📱 Fully responsive and centered layout
- ⚡ Built with React + Vite

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

## Tech Stack

- React 19
- Vite 7
